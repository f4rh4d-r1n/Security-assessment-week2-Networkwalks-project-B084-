# Security-assessment-week2-Networkwalks-project-B084-
Executed a comprehensive cybersecurity reconnaissance and network discovery project in Kali Linux. Conducted passive footprinting, DNS enumeration, WAF detection, and web fingerprinting using Whois, nslookup, dnsrecon, WhatWeb, wafw00f, and cURL, alongside active local network mapping and port scanning with Nmap and Zenmap.
